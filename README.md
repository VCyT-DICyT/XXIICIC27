# XXII Congreso Internacional de Investigación Científica (XXII CIC 2027)

Sitio web del XXII CIC, organizado por el Ministerio de Educación Superior, Ciencia y Tecnología (MESCyT) de la República Dominicana.

- **Fechas:** 22 al 25 de junio de 2027
- **Sede:** Universidad Nacional Pedro Henríquez Ureña (UNPHU), Santo Domingo
- **Marco:** Semana Dominicana de la Ciencia, 20 al 27 de junio de 2027

El sitio es una sola página (`index.html`) publicada con GitHub Pages.

## Cómo actualizar el contenido

Todo lo que falta por completar (fechas, comités, conferencistas, programa, contacto, enlace del formulario) se edita en **un solo archivo: [`contenido.yml`](contenido.yml)**. No hace falta tocar `index.html`.

1. Abra [`contenido.yml`](contenido.yml) y pulse el lápiz (✏️ *Edit this file*).
2. Escriba los datos entre las comillas, siguiendo las notas y ejemplos del propio archivo.
3. Pulse **Commit changes** y escriba una frase sobre lo que cambió (por ejemplo, «Fechas de la convocatoria»).
4. En 1 o 2 minutos la página muestra el cambio.

Si algo no aparece, revise que se respetaron los espacios al inicio de cada línea y las comillas. Cualquier cambio se puede deshacer desde el historial del archivo (*History*).
