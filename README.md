# XXII Congreso Internacional de Investigación Científica (XXII CIC 2027)

Sitio web del XXII CIC, organizado por el Ministerio de Educación Superior, Ciencia y Tecnología (MESCyT) de la República Dominicana.

- **Fechas:** 22 al 25 de junio de 2027
- **Sede:** Universidad Nacional Pedro Henríquez Ureña (UNPHU), Santo Domingo
- **Marco:** Semana Dominicana de la Ciencia, 20 al 27 de junio de 2027

El sitio es una sola página (`index.html`) publicada con GitHub Pages.
